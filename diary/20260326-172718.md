# 2026-03-26 implement の PR 起点フロー実装

## レビュー

指摘なし。以下の点がレビューで確認された。

- `fetch_and_checkout_branch` の動作: `git fetch origin <branch>` でリモート追跡 ref を更新し、`git checkout <branch>` でローカルブランチが存在しない場合に origin/branch から自動追跡ブランチを作成する。GitHub Actions の新規ランナーでは常にローカルブランチが存在しないため正常動作する。
- `target.number` の null 安全性: `_build_header` 内で PR ターゲットの場合に `target.number` を参照するが、`run_command` で `assert target.number is not None` が通過済みのため null になることはない。

## 手こずったこと

特になし。Issue 起点フローとの対称性がはっきりしていたため、実装方針が決まりやすかった。

ローカル PR への implement の場合（`target.backend == "local"`）は `github_client` が `None` になり `assert` が発火する問題に気づき、`CommandError` でユーザーフレンドリーなエラーに変更した。この考慮が計画段階で漏れていた。`_is_github_target` チェックを追加することで解決した。
