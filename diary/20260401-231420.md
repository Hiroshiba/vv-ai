### 設計判断

`vv-ai.yml` を `.gitignore` に入れていたのはローカルテスト時に誤コミットを防ぐためだったが、GitHub Actions runner 上に config が存在しなくなるという問題があった。`vv-ai.yml` はリポジトリの設定ファイルであり本来コミット対象なので、`.gitignore` から削除した。

Claude Code CLI のインストールは npm 経由（`@anthropic-ai/claude-code`）を選択した。公式推奨の curl インストールはスクリプトが PATH 設定を `.bashrc` 等に書き込むため、GitHub Actions のステップ間では PATH が引き継がれず追加対応が必要になる。npm グローバルインストールはその問題がなく CI で扱いやすい。
