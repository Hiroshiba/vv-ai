## 見逃しの考察

- `is_error=True` の exit code 問題は設計時に見落としていた。`execute_provider` が正常 return する経路と例外経路を分けた設計で、正常 return 側の status を exit code に反映する処理が抜けていた。
- `~/.claude/**` のチルダ記法は他パスとの対称性を確認していれば気づけた。定数を書くときに同一リストの他要素と比較する習慣が必要。
- `instruction or command` は AGENTS.md の「空文字に別の意味を持たせるな」を書いていた時点で気づくべきだった。`or` を使う箇所で None 判定か falsy 判定かを意識する必要がある。
