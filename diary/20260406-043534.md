## G-Live-30 失敗の原因

`git_ops.py:get_default_branch` が `git rev-parse --abbrev-ref origin/HEAD` を実行するが、GitHub Actions の `actions/checkout@v4` はデフォルトで `origin/HEAD` を設定しない。implement コマンドがブランチ作成時にデフォルトブランチを取得しようとして失敗した。

ローカルテスト Phase 15-17 ではローカル環境に `origin/HEAD` が存在するため発覚しなかった。dry-run テスト Phase 20 では implement を codex で実行しており、その時点では成功しているため、当時の環境で origin/HEAD が設定されていた可能性がある。あるいは dry-run では `git push` が不要なためブランチ作成のパスが異なる可能性がある。

修正方針: `origin/HEAD` が取れない場合に `gh api repos/{owner}/{repo}` からデフォルトブランチを取得するフォールバック、または workflow の checkout ステップで `git remote set-head origin --auto` を実行する。
