### バグ: --permission-mode の無効な値

`provider_execution.py` で `--permission-mode "accept"` を渡していたが、Claude Code CLI はこの値を認識しない。

正しい選択肢を調査した。

- `bypassPermissions`: 公式ドキュメントで「コンテナ/VM 専用」と明記されている
- `acceptEdits` + `autoAllowBashIfSandboxed: true`: ファイル編集を自動承認し、sandbox 内 Bash は permission-mode に関係なく自動承認される。onetask でも同じ組み合わせを使用済み

`acceptEdits` に変更し、settings の sandbox に `autoAllowBashIfSandboxed: true` を追加した。

## 見逃しの考察

`--permission-mode accept` という無効な値を実装時に書いてしまったのは、Claude Code CLI のオプションを実際に確認せず推測で書いたため。Codex テスト時は codex のオプションをきちんと調査したが、claude 側は調査が不十分だった。

## 手こずったこと

`bypassPermissions` か `acceptEdits` + `autoAllowBashIfSandboxed` かの判断。`bypassPermissions` はセキュリティ的にシンプルだが公式がコンテナ/VM 専用と明記しているため採用できなかった。onetask の実装を参照することで最適な組み合わせを特定できた。
