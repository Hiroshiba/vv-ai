## G-Live-50 失敗の原因

`command_handler.py` L53 で `github_client = build_github_client() if _is_github_target(target) else None` としている。`issue` コマンドは target を持たないため `_is_github_target(target)` が False になり、`github_client` が None のまま後処理に渡される。`_handle_issue_post_execution` で `github_client is None` の場合に `[local]` として Issue 作成をスキップしてしまう。

修正方針としては、`_handle_issue_post_execution` 内で `github_client is None` の場合に `build_github_client()` でフォールバックすることが考えられる。`_post_fork_patch_fallback` には既に同様のフォールバックがある。
