### 修正したバグ

1. **`get_default_branch` が `origin/HEAD` 未設定で失敗**: `git rev-parse --abbrev-ref origin/HEAD` を `gh repo view --json defaultBranchRef` に変更。git ローカル状態に依存せず GitHub API から取得するようにした。
2. **`maintainer_can_modify` の型不正**: Python の `True` が文字列 `"True"` として `gh api -F` に渡され HTTP 422。`'true'`/`'false'` 文字列に変換するよう修正。
3. **空 PR 作成の防止**: AI が変更コミットを作らなかった場合に PR 作成を試みて HTTP 422。push 前に `has_commits_ahead` でコミット有無をチェックし、変更がなければスキップするようにした。
