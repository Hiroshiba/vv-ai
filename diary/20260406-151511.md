### 原因

Ubuntu 24.04+ の GitHub-hosted runner で AppArmor が unprivileged user namespaces をブロックしており、Codex の bubblewrap sandbox が初期化に失敗する。

- エラー: `bwrap: loopback: Failed RTM_NEWADDR: Operation not permitted`
- `exec_command` と `apply_patch` の全呼び出しが失敗
- Codex は GitHub API の MCP ツールにフォールバックしたが、non-interactive モードでは承認が出ず `user cancelled MCP tool call` で失敗
- さらにブランチが未 push のため GitHub API 経由でもファイル作成不可

### 解決策

`openai/codex-action` の実装を調査し、同等のセットアップを特定した。

1. ワークフローに sysctl ステップを追加して bwrap の前提条件を解決する
   - `kernel.unprivileged_userns_clone=1`
   - `kernel.apparmor_restrict_unprivileged_userns=0`
2. `--full-auto` を `--sandbox workspace-write` + `approval_policy="never"` に分離する
   - `--full-auto` の実体は `--sandbox workspace-write --ask-for-approval on-request` であり、non-interactive では `on-request` が止まりやすい
