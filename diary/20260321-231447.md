## 実施内容

- `session_artifact.py` を追加し、`.vv-ai/artifacts/<workflow-id>/sessions/<artifact-name>/` に session artifact 本体を保存する処理を実装した。
- 保存内容として `meta.json`、`git-diff.patch`、`git-staged.patch`、`git-status.txt`、必要時の `provider-session/` を定義した。
- session artifact 保存成功後に、同じ `workflow_id` と `session key` で session manifest も保存するようにした。
- artifact 名は `vv-ai-session__<target>__<provider>__<lane>__<workflow-id>` 形式に統一した。

## レビュー対応

- 自動レビューのうち、GitHub Actions の detached HEAD で保存できない点、untracked file の中身が保存されない点、`copytree()` 失敗時に一時 directory が残る点は実害があるため修正した。
- `branch_name` は detached HEAD を許容して `HEAD` も保存できるようにし、untracked file は `untracked/` 配下へ実体コピーするようにした。
- provider session directory の copy 失敗時は `shutil.Error` も捕捉し、一時 directory を必ず掃除するようにした。
