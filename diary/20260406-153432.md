## 実施内容

G-Live-30 implement テストの再実行で、Codex がファイル変更したがコミットされず「変更コミットがないため push と PR 作成をスキップします」になる問題を調査・修正した。

### 原因

Codex の `workspace-write` sandbox は設計上 `.git` ディレクトリを read-only にする。bwrap でも Seatbelt でも同じ仕様。そのため AI 内で git commit ができない。

session artifact を復号して確認したところ、Codex はコード変更を行っていたが `git commit` が sandbox に拒否されていた。

### 修正内容

requirements.md に「git commit / push / PR 作成は非 AI ラッパーが実施」と明記されており、この設計に合わせた。

- prompt.py: 「git commit してください」を削除し「ファイル変更のみ行ってください。git の操作は不要です」に変更。`git add -A` でコミットされる旨と一時ファイル削除の注意を追記。
- git_ops.py: `commit_all_changes` を追加。ワーキングツリーの全変更を `git add -A && git commit` する。
- command_handler.py: Issue 起点・PR 起点の両方の後処理で、push 前に `commit_all_changes` を呼ぶよう修正。
