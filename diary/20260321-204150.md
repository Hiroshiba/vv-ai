# Report

## Summary
`RawInput` を `ResolvedCommand` へ正規化する層を追加し、CLI 入口で command ごとの必須項目と target 指定の整合を検証できる状態にした。あわせて `plan.md` の該当タスクを完了済みに更新した。

## Changes
- `src/vv_ai/resolve.py` を追加し、`ResolvedCommand`、`ResolutionError`、`resolve_raw_input()` を実装した。
- command 未指定時は `reply` を既定値にし、`reply` / `plan` / `implement` / `review` では target 必須、`reply` / `issue` では instruction 必須とする正規化ルールを追加した。
- `target_url` がある場合はそれを優先し、`target_type` と `target_number` は両方そろわない限りエラーにするようにした。
- `issue` コマンドでは `repo` 未指定時に `repository_full_name` を既定値として採用するようにした。
- `issue_comment` / `workflow_dispatch` の event で必要な最低限のメタデータ不足を正規化エラーとして検出するようにした。
- `src/vv_ai/cli.py` を更新し、`RawInput` 構築後に正規化まで実行してエラー表示へ反映するようにした。
- `plan.md` の「`RawInput` から `ResolvedCommand` への正規化を実装する」を完了済みに更新した。
