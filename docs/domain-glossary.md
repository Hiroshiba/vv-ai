# ドメイン用語集

このドキュメントは、vv-ai のドメイン用語を説明するためのものです。
ドキュメントやコメントで使うと読者が迷いやすい語を書く。
一般的な製品名、コマンド名、ファイル名、コード内でしか使わない語は、必要な場合だけ書く。

| 用語 | 説明 | 避けたい言い方 |
| --- | --- | --- |
| vv-ai | GitHub Issue や PR から AI 作業を起動するツール。 |  |
| AIクライアント | AI 作業を実行するコマンドラインツール。 | provider |
| 対象 Issue | vv-ai が作業する GitHub Issue。 | target |
| 対象 PR | vv-ai が作業する GitHub PR。 | target |
| サブ Issue | タスク分割で作成する子 Issue。 |  |
| 実行成果物 | GitHub Actions に保存する実行結果のファイル。 | artifact |
| セッション | AI 作業の継続状態。 | session |
| 作業ブランチ | 実装や PR 更新で変更を積むブランチ。 | head branch |
| ワークフロー | GitHub Actions の実行定義。 | workflow |
| ドライラン | GitHub への反映を行わず、実行内容を確認する実行方式。 | dry-run |
