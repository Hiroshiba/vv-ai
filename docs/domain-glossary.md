# ドメイン用語集

ユーザー向け文章で使うドメイン用語を定義する。英字語を避ければ一意に自然な日本語になる語は書かない。

| 用語 | 説明 | 避けたい言い方 |
| --- | --- | --- |
| vv-ai | GitHub Issue や PR から AI 作業を起動するツール。 |  |
| AIクライアント | Codex CLI などの AI 作業をするツール。 | provider |
| AIクライアント向けファイル | AIクライアントへ渡す指示やスキルのファイル群。 | provider asset |
| セッション | AIクライアントが前回の作業文脈を引き継ぐための状態。 | session |
| セッション継続モード | 前回のセッションをどう引き継ぐかを指定するオプション。 | session_mode |
| セッション区分 | セッションの共有範囲を決める区分。main や review などがある。 | lane |
| 制御処理 | AI を呼ぶ前後に vv-ai 本体が担う処理。git 操作・push・コメント投稿などが含まれる。 | wrapper, runner |
