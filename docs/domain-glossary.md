# ドメイン用語集

ユーザー向け文章で使うドメイン用語を定義する。アルファベット表記の英単語を避ければ一意に自然な日本語になる語は書かない。

| 用語 | 説明 | 避けたい言い方 |
| --- | --- | --- |
| vv-ai | GitHub Issue や PR のコメント・ラベルから AI に作業を頼むツール。 |  |
| AIクライアント | Codex CLI や Claude Code CLI など、AI を実行する CLI ツール。 | provider |
| AIクライアント向けファイル | AIクライアントの設定やスキルなど、vv-ai が AIクライアントへ用意するファイル群。 | provider asset |
| セッション | AIクライアントが前回の作業文脈を引き継ぐための保存状態。 | session |
| セッション継続モード | 前回のセッションをどう引き継ぐかを指定するオプション。 | session_mode |
| セッション区分 | セッションの共有範囲を決める区分。main や review などがある。 | lane |
| 制御処理 | AI を呼ぶ前後に vv-ai 本体が担う処理。git 操作・push・コメント投稿などが含まれる。 | wrapper, runner |
| コマンド | vv-ai が実行する作業単位。`confirm` / `implement` / `review` などの種別がある。 | 工程 |
| コマンドリクエスト | コメントやラベルでコマンドを発する行為。`next` の履歴はリクエストの並びから組み立てる。 | 工程入力、工程起動 |
